# Решения владельца и открытые вопросы

## Принято
- Отдельный репозиторий. Almanac - необязательный модуль, нотч полезен и без него. Это экосистема, а не жёсткая связка.
- Своё и оригинальное - только маскот. Остальной интерфейс острова делается самым удобным и качественным способом, даже если похоже на другие нотч-приложения.
- Маскот: минимализм и техничность, без рта, без мультяшной милоты. Крупные глаза, читаемость в маленьком нотче с учётом камеры. Росток и подобные «милые» формы отвергнуты.
- Обязательно: реакция на клики, слежение за курсором, все взаимодействия из прототипа.
- У острова три состояния. На Windows - та же полоса, что на Mac, а в закрытом состоянии плоская плитка, не кружок и не пилюля.
- Полоса в полуоткрытом всегда по центру экрана. При лимите в нотче показывается коротко: «Лимит 1:23».
- На успехе маскот не машет рукой. Рука - отдельный кругляш.
- Предметы модулей - через отдельный реестр, чтобы легко добавлять новые.
- Танец - это настроение маскота, пока играет музыка. Событие «Праздник» - для поводов: например, все привычки отмечены.
- Приватность важнее удобства: никаких внешних запросов, кроме подключённых сервисов.
- Целевой стек: Tauri 2 + TypeScript (рендер на канвасе) + Rust. Запасной вариант для Mac - нативная оболочка с тем же рендером.
- Устройства владельца: Mac (основной), Windows, iPhone.
- Claude Code владелец запускает в основном через Claude Desktop, иногда в терминале.
- Языки интерфейса: русский и английский.
- Клавиши ответа в окне - глобальные ⌥Y / ⌥N / ⌥1-3, только пока открыт вопрос (2026-10-14).
- Музыка на Mac - MediaRemote через хелпер в `/usr/bin/perl` (как Boring Notch / mediaremote-adapter): любой плеер, включая браузеры (2026-10-14).

## Открыто (спросить владельца на своём этапе)
- В `~/.claude/settings.json` владельца стоят хуки NotchBuddy, в том числе `PermissionRequest` и `AskUserQuestion` с ожиданием 120-130 с. Claude Code запускает хуки параллельно, и если ответят оба приложения, порядок не определён. Оставить оба или убрать NotchBuddy?
- Календарь на Windows: Outlook, Google или пока без календаря. Сейчас модуль пустой («Календарь недоступен»).
- Поведение в полноэкранных приложениях.
- Как Almanac отдаёт данные: локальное API или файл.
- Телефон: PWA в локальной сети или через свой сервер.
