# Решения владельца и открытые вопросы

## Принято
- Планка качества с этапа 9 (2026-10-19): цель - лучше coucou и Grok Bot; сцена готова только с роликом рядом с обоими; прототип - нижняя планка, отличия пишутся в CHANGES без ожидания подтверждения, о заметных - сообщить в конце сообщения. Правила - CLAUDE.md, «Планка качества».
- Отдельный репозиторий. Almanac - необязательный модуль, нотч полезен и без него. Это экосистема, а не жёсткая связка.
- Своё и оригинальное - только маскот. Остальной интерфейс острова делается самым удобным и качественным способом, даже если похоже на другие нотч-приложения.
- Маскот: минимализм и техничность, без рта, без мультяшной милоты. Крупные глаза, читаемость в маленьком нотче с учётом камеры. Росток и подобные «милые» формы отвергнуты.
- Обязательно: реакция на клики, слежение за курсором, все взаимодействия из прототипа.
- У острова три состояния. На Windows - та же полоса, что на Mac, а в закрытом состоянии плоская плитка, не кружок и не пилюля.
- Полоса в полуоткрытом всегда по центру экрана. При лимите в нотче показывается коротко: «Лимит 1:23».
- На успехе маскот не машет рукой. Рука - отдельный кругляш.
- Предметы модулей - через отдельный реестр, чтобы легко добавлять новые.
- Танец - это настроение маскота, пока играет музыка. Событие «Праздник» - для поводов: например, все привычки отмечены.
- Приватность важнее удобства: никаких внешних запросов, кроме подключённых сервисов.
- Целевой стек: Tauri 2 + TypeScript (рендер на канвасе) + Rust. Запасной вариант для Mac - нативная оболочка с тем же рендером.
- Устройства владельца: Mac (основной), Windows, iPhone.
- Claude Code владелец запускает в основном через Claude Desktop, иногда в терминале.
- Языки интерфейса: русский и английский.
- Клавиши ответа в окне - глобальные ⌥Y / ⌥N / ⌥1-3, только пока открыт вопрос (2026-10-14).
- NotchBuddy - отдельное приложение владельца, к проекту не относится. Его хуки в `~/.claude/settings.json` не трогаем (2026-10-14).
- Календарь на Windows - выбор в настройках модуля, что подключить (Outlook, Google или ничего). Делается на этапе 7 (2026-10-14).
- Календарь на Windows без OAuth: классический Outlook по COM, секретная ссылка iCal (Google, Outlook.com, iCloud, Яндекс и др.) или ничего (2026-10-17). OAuth Google - позже: приложение open source, общий Client ID без верификации Google ограничен 100 пользователями, а свой Client ID у каждого пользователя - слишком много действий.
- Музыка на Mac - MediaRemote через хелпер в `/usr/bin/perl` (как Boring Notch / mediaremote-adapter): любой плеер, включая браузеры (2026-10-14).
- Модули как в coucou (github.com/Louis-CFM/coucou, `MAX_DECLARED`): одновременно включено не больше 5 - карточка в фокусе и сетка 2×2 открытого острова (2026-10-18). Claude Code считается, только пока включён: выключенный освобождает место (2026-10-19).
- Vercel: карточка как в coucou - «Vercel · Деплои», три последних деплоя с точками состояния и возрастом, ↗ на vercel.com; маскот серо-сиреневый `#C9C3E8`, свой предмет - ракета (2026-10-18).
- Grafana: карточка «Grafana · Алерты» - горящие (красные) и ожидающие (жёлтые) правила, ниже выбранный в настройках дашборд: ссылка, последнее значение и мини-график одной панели за час; событие error, когда правило загорелось, success - когда прошло; маскот между оранжевым и красным `#FF8C66`, предмет - монитор с графиком, значок - пульс (2026-10-18).
- Notion: карточка как в coucou - «Notion · Недавние», три последние изменённые страницы (значок, название, возраст), строка открывает страницу; маскот бумажно-серый `#E4DFD3`, предмет - карандаш; событие, когда страницу правит кто-то другой (2026-10-18).
- Almanac (2026-10-18): нотч входит в аккаунт Almanac (почта и пароль или код из письма) и вызывает общее API интеграций Almanac - `today_habits(p_date)` и `toggle_habit(p_habit, p_date)` (Supabase RPC, описание - `almanac-app/docs/API.md`). API не написано под нотч: любой клиент может им пользоваться, приложения связаны только через него. Карточка - привычки на сегодня, сначала неотмеченные; нажатие отмечает в Almanac; события - отмечено в другом месте, все отмечены (праздник), напоминание вечером.
- Релиз (2026-10-18): пока без подписи Apple и Windows - в README и тексте релиза инструкция, как открыть в первый раз; подпись и нотаризация включаются секретами в `.github/workflows/release.yml`, когда появится аккаунт. Установщики - GitHub Releases, собирает GitHub Actions по тегу `v*` (Mac - один universal .dmg, Windows - Setup.exe), релиз создаётся черновиком. Автообновление с выключателем (по умолчанию включено) - исключение из правила «сеть только к подключённым сервисам». Первый запуск - мастер по шагам (язык, Claude Code, календарь, модули, запуск при входе), запуск при входе по умолчанию включён, на Mac .dmg с перетаскиванием, понятные сообщения об ошибках.
- Иконка приложения и трея - маскот (2026-10-18).
- Голос текстов (2026-10-19): приветствие говорит от лица маскота («Привет! Я живу у выреза камеры»), окна настроек, установки и удаления - не от первого лица («Раз в день приложение смотрит…»).
- Установщик и деинсталлятор (2026-10-18, этап 8g): окно Setup.exe - маленькое приложение Tauri на WebView2 с живым маскотом приветствия; если WebView2 в системе нет, Setup запускает обычный мастер NSIS (он сам ставит WebView2). Галочка «Ярлык на рабочем столе» - по умолчанию выключена. Галочка «Удалить настройки и данные» при удалении - по умолчанию снята, хуки Claude Code снимаются всегда.

## Открыто (спросить владельца на своём этапе)
- Поведение в полноэкранных приложениях.
- Код из письма для входа в нотч: нужен `{{ .Token }}` в шаблоне письма Magic Link в Supabase Almanac (ссылку оставить). Без этого работает только вход по паролю.
- Телефон: PWA в локальной сети или через свой сервер.
- Вкладка «+» - полка файлов вместо списка модулей (2026-10-18). Держит все брошенные файлы, пока их не отправят, как в boring.notch. Срок хранения - 10 минут. Экрана выбора после броска нет: пользователь сам перетаскивает файл, куда нужно. Отправка письмом - нужна. Подробно - `docs/PLAN.md`, этап 9.
