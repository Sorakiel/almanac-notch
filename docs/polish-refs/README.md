# Референсы этапа 9

Скриншоты владельца, чужое приложение. Это планка качества для этапа 9: наполнение, раскладка, кнопки, свечение, состояния маскота. Реализация должна быть **не хуже по каждому пункту ниже**. Отличия от `prototype/island-prototype.html` всё равно идут через `docs/CHANGES.md` и подтверждение владельца.

Чего в кадрах не видно: анимации, звуки, наведение. Их снимать с живых приложений: coucou (github.com/Louis-CFM/coucou, у владельца установлен `/Applications/Coucou.app`) и AB.design (установлен у владельца). Записать экран, разобрать тайминги, кривые, наведение и звуки так же подробно, как кадры ниже, и для каждого решения записать, зачем оно.

## Общая система

- **Свечение фона по типу события** - большое мягкое радиальное пятно снизу или сбоку карточки, цвет говорит, что случилось:
  - янтарный/оранжевый - нужно разрешение (2);
  - бирюзовый - вопрос (3);
  - зелёный - агент закончил (6);
  - индиго/фиолетовый - чат и итоги недели (4, 5).
- **Свечение маскота** совпадает по смыслу: голубое, пока агент думает (1-3), зелёное, когда готов или ждёт (4-6).
- **Значок над маскотом**: голубая пилюля с тремя белыми точками - думает; зелёный кружок с тёмной обводкой - готов.
- **Маскот**: белое тело, розовые щёки, чёрные глаза; глаза меняют форму по состоянию (круглые - активен, узкие черточки - спокоен/читает).
- **Кнопки** - пилюли высотой около 44 px, крупный полужирный текст:
  - главная - белый фон, чёрный текст;
  - второстепенные - тёмные полупрозрачные, слегка окрашены в цвет события (коричневатая на 2, зеленоватая на 6).
- **Типографика**: заголовок - белый полужирный; пояснение - тот же размер, серый ~55 %; подписи - мельче и серее.
- **Карточки**: тёмный фон чуть светлее острова, радиус ~24 px, тонкая светлая рамка ~6 %.
- **Верхняя панель**: слева «главная», «чат», «+»; активная вкладка - белая иконка в серой пилюле, неактивные - серые. Справа «настройки» и «динамик» (выключатель звука).
- **Строка-шапка события**: белая точка статуса, полужирное имя источника («VS Code»), серым - что происходит («требует разрешения», «Claude Code завершил»).

## 1. Главная - `1-home-agents.png`

- Две карточки рядом: слева агент, справа подключения.
- Карточка агента:
  - маскот с голубым свечением и значком «думает»;
  - шапка: точка, «VS Code», серым «Claude Code», справа счётчик «2/2» (какой агент из скольких) и круглая тёмная кнопка со стрелкой ↗ «открыть»;
  - вторая строка серым - текущее действие: «Reading auth/middleware.ts»;
  - третья строка - раскрывающая стрелка «>», имя файла крупно, дифф: зелёный «+11», красный «−5».
- Карточка подключений: сетка из двух колонок, чипы-пилюли.
  - Чип: тёмная заливка, тонкая рамка в цвет сервиса, слева маленький маскот цвета сервиса (оранжевый, красный, синий) с глазами, справа название по центру, серое полужирное.
- Не копировать: в чипе «claude-desktop» маскот налезает на текст - это баг референса.

## 2. Разрешение - `2-permission.png`

- Одна широкая карточка во всю ширину.
- Шапка: точка, «VS Code», серым «требует разрешения».
- Команда - моноширинным шрифтом в тёмной скруглённой плашке с тонкой рамкой.
- Три кнопки в ряд: «Отклонить» (тёмная), «Разрешить» (белая, главная, в центре), «Всегда» (тёмная с тёплым оттенком).
- Тёплое янтарное свечение снизу по центру, под кнопками.

## 3. Вопрос - `3-question.png`

- Карточка растёт по высоте под содержимое, маскот остаётся по центру слева.
- Сверху серым «Claude Code спрашивает», справа подчёркнутая ссылка «Ответить в терминале».
- Мелкая серая метка темы («Reporter»), под ней сам вопрос полужирным.
- Варианты - строки во всю ширину: тёмная заливка, тонкая рамка, радиус ~10 px; полужирное название и серое пояснение под ним.
- Внизу пилюля «Другое...» для своего ответа.
- Бирюзовое свечение снизу.

## 4. Чат - `4-chat.png`

- Вкладка «чат» активна.
- Сообщение пользователя - справа, в серой скруглённой пилюле.
- Ответ модели - слева, без пузыря, обычный текст, печатается потоком.
- Над полем ввода справа - выбор модели: пилюля с цветной точкой статуса, «gemma3:4b» и стрелками ⌃⌄.
- Поле ввода: скруглённое, плейсхолдер «Продолжить...», цветная каретка, иконка микрофона, круглая белая кнопка отправки со стрелкой вверх.
- Маскот: зелёный значок, зелёное свечение, глаза узкие (читает).
- Фиолетовое свечение снизу по центру.

## 5. Итоги недели - `5-week-summary.png`

- Заголовок «Итоги недели» лавандовым акцентом, справа серым диапазон дат «окт. 5 – окт. 11».
- Ряд крупных полужирных цифр с мелкими серыми подписями: часы программирования, сессии, файлы, команды, строки «+3412 / -891», вопросы.
- Кнопки: белая «Поделиться картинкой», тёмная «OK».
- Индиго-фиолетовое свечение справа.
- Не копировать: подписи «lines» и «questions» не переведены - баг референса.

## 6. Агент закончил - `6-done.png`

- Шапка: точка, «VS Code», серым «Claude Code завершил».
- Итог работы - одна строка полужирным, обрезается многоточием.
- Кнопки: белая «Открыть терминал», тёмно-зелёная «OK».
- Зелёное свечение снизу слева, маскот с зелёным значком.
