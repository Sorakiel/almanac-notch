# Спецификация острова и маскота

Источник истины - `prototype/island-prototype.html` (дальше «прототип»). Этот документ описывает его словами и числами, чтобы ничего не потерялось при переносе. Если текст и прототип расходятся, прав прототип: открой функцию, на которую ссылается раздел, и сделай как там. Если находишь такое расхождение, исправь и этот документ.

Эталонные кадры каждого состояния лежат в `reference/screens`, движение - в `reference/video`. Как сверять реализацию с прототипом, описано в `docs/PARITY.md`.

Единицы: длины - в пунктах (CSS px, 1 pt = 2 пикселя ретины), время - в секундах, если не сказано иное. `R` - радиус маскота, `b = 0.92 * R` - его полувысота.

## 1. Маскот

### 1.1 Тело - `BODY`, `bodyPath`, `widthAt`, `drawSeed`

- Форма - «яйцо»: суперэллипс со степенью `N_EXP = 2.3`, чуть уже сверху. Ширина по высоте `yn ∈ [-1, 1]` (−1 сверху): `widthAt(yn) = yn > 0 ? 1 + 0.05*yn : 1 - 0.13*yn²`.
- Контур - 80 точек, сглаженных квадратичными кривыми через середины отрезков.
- Заливка `col.body`, поверх в клипе тела вертикальный градиент: `rgba(255,255,255,0.18)` сверху → прозрачный `shade` на 45% → `shade` с альфой 0.75 снизу.
- На светлых цветах (`chalk`, `ice`, `steel`) и только на большой сцене - обводка 1 px `rgba(0,0,0,0.08)`.
- Рта нет и не будет. Это осознанное решение владельца: минимализм и техничность, без мультяшной милоты.
- Цвета персонажа (`COLORS`), по умолчанию `chalk`:

| ключ | имя | body | shade | eye |
|---|---|---|---|---|
| chalk | Мел | #EEEDE8 | #B9B7AE | #16171A |
| steel | Сталь | #B5BDC6 | #76808C | #101317 |
| signal | Сигнал | #FF7A3D | #C24E19 | #190F0A |
| ice | Лёд | #AEDBEA | #68A9C1 | #0D1A21 |
| graphite | Графит | #5B6069 | #32363D | #F3F2EE |

- В карточках модулей маскот перекрашивается в цвет модуля (`MODULE_COL`): claude #F0B08A/#C27A52, github #B8C2FF/#7D88D6, cal #FFD27A/#D6A23E, music #9EE6B8/#5DB884, almanac #F4A9C6/#C9708F; глаза у всех #16171A.

### 1.2 Поза - `pose`

- Дыхание: `sy = sq * (1 + amp * sin(2πt / период))`, `amp = 0.016` (во сне 0.03), период 3.6 (во сне 5.2), умножается на `S.breath`, при «меньше движения» × 0.4.
- Сохранение объема: `sx = max(sy, 0.3)^-0.6 * (1 + puff*0.06)`.
- Позиция: `posX`, `posY` в единицах `R`. В нотче и в карточке (`mini`) смещения ужаты: `px * 0.15` в пределах ±0.35, `py * 0.35` в пределах [−0.45, 0].
- Прятанье: `hide ∈ [0, 1.2]` опускает тело вниз на `hide * b * sy` (в мини × 0.55) с клипом по земле.
- Наклон `lean` - вращение вокруг точки опоры (низ тела).

### 1.3 Пружины - `Spring`, `kz`, `GROUP`

Полунеявный Эйлер с фиксированным шагом 1/240 с, `c = 2ζ√k`. Группы:

| группа | k | ζ | кто |
|---|---|---|---|
| body | S.bodyK = 320 | S.bodyZ = 0.42 | posX, sq, lean |
| eye | S.eyeK = 260 | S.eyeZ = 0.78 | lookX, lookY |
| expr (по умолчанию) | S.exprK = 200 | S.exprZ = 0.85 | happy, grump, wide, hide, puff, hand, work, think, posY при перетаскивании |
| fast | 1600 | 0.9 | lid (веко) |
| slow | 40 | 0.95 | glow |
| island | 190 | 0.78 | earL, earR, ih, nw (геометрия острова) |
| badge | 260 | 0.6 | badge |
| fade | 160 | 1 | halfA, openA, alertA |
| spin | 70 | 1 | spin (морф глаз в спиннер) |

- `posY` не пружина: гравитация `GRAV = 34 R/с²`. При приземлении со скоростью > 0.6 даёт сплющивание `sq.v -= v*0.6`, при скорости > 4 - отскок `-v*0.16`.
- Перетаскивание: `posX` и `posY` тянутся пружиной 900/0.85.
- Прыжок `hop(power)`: на 0.11 с `sq = 0.8` (приседание), затем `posY.v -= power`, `sq.v += power*1.4`.
- Сила наклона от горизонтальной скорости: `lean.t += clamp(posX.v*0.05, ±0.4)`.

### 1.4 Глаза - `eyesOf`, `drawEyes`, `drawSpinEyes`, `eyesOrSpin`

- Глаза - тёмные пилюли (скругление = половина меньшей стороны).
- Масштаб `boost = S.eyeSize (1.3) × (notch: S.notchEye 1.3 | card: 1.12 | сцена: 1)`.
- Ширина `ew = 0.19R·boost·(1 + 0.18·wide)`, высота `eh = 0.4R·boost·(1 + 0.14·wide)`.
- Расстояние между центрами `0.46R·(0.72 + 0.28·boost)·(1 − 0.1·|lx|)`.
- Взгляд `lx, ly ∈ [−1.5, 1.5]`, движение по дуге: `fx = sin(0.95·lx)·0.19R`, `fy = sin(0.95·ly)·0.26b`. Базовая высота глаз `−0.04b`.
- Перспектива: глаз со стороны взгляда сужается `1 − 0.24·max(0, side·lx)`.
- Вертикальное сжатие при взгляде вверх или вниз: `vk = 1 − 0.2·|ly|` на высоту.
- Взгляд вниз опускает глаз: `+0.1·eh·max(0, ly)` (верх «под веком»).
- Веко `lid ∈ [0, 1.1]`: высота × lid, минимум `0.055R`.
- Моргание: каждые `S.blinkEvery (3.6) × (0.55…1.45)` с на 0.075 с, в 18% случаев второе через 0.22 с. Во сне не моргает (веко 0.05).
- Довольные глаза (`happy`) - морф, а не кроссфейд: при `happy < 0.5` пилюля сплющивается до высоты `0.55·w`, при `happy ≥ 0.5` линия изгибается дугой (толщина `0.58·w`, ширина `0.22…0.95·w`, вершина на `−0.44·eh`).
- Дуется (`grump`): верх глаза срезан наклонной линией, внутренний край ниже.
- Свечение (`eyeGlow`): копия глаз цвета состояния с `shadowBlur = 0.4R` (в мини 0.5R), толще на `0.2w`, под тёмными глазами. Таблица - раздел 1.9.
- Перегруз: глаза морфятся в спиннер пружиной `spin`. При `k < 0.5` пилюля сжимается в точку, при `k ≥ 0.5` из точки вырастает вращающаяся дуга (`9 рад/с`, глаза крутятся навстречу, длина дуги `1.35π·g`).

### 1.5 Точка статуса - `drawBadge`

Справа снизу на теле (`0.7R, 0.6b` в локальных), радиус `0.13R` (в нотче 3.3), кольцо цвета фона толщиной `0.05R` (в нотче 1.6). Пружина `badge` с перелётом. Цвет - цвет статуса. При «внимании» пульсирует `1 + 0.18·sin(7t)`. Не показывается при приветствии и при лимите (там уже есть часы).

### 1.6 Рука - `drawHand`

Отдельный кругляш (не приделанная лапа) справа от тела: радиус `0.17R`, радиальный градиент от осветлённого body к shade, машет по дуге `−0.9 + 0.55·sin(14t)`. Сейчас появляется только в приветствии (между 1.95 и 3.05 с после варпа). На успехе руки нет - это решение владельца.

### 1.7 Слои поведения - `update`

Каждый кадр цели собираются заново в объект `T` в таком порядке (позже - сильнее):

1. **Фон.** Если курсор над островом - смотрит на курсор из маскота острова. Иначе: во сне - веко 0.05, взгляд вниз 0.35. Если курсор двигался последние 4 с - следит за ним (`tanh(dx / 2.6R)`, `tanh(dy / 1.8R)`, × `S.lookRange`). Иначе осматривается: каждые 1.4…3.4 с случайная точка (30% - в центр), иногда моргает.
2. **Настроение модуля** (`moduleMood`, только в открытом острове, на «Главной», без событий): раздел 2.8.
3. **Взаимодействие:** держат на весу → перегруз → прячется → дуется → гладят → радуется → тычок (прищур 0.2 с).
4. **Событие** - раздел 1.9.
5. Моргание и принудительное сплющивание прыжка поверх всего.

Текущий текст каждого слоя выводится в три плашки под сценой (`layerText`). Подсвечивается самый сильный слой.

### 1.8 Взаимодействия - `poke`, обработчики ввода

| действие | реакция |
|---|---|
| курсор | следит глазами (сцена и остров) |
| клик по телу | тычок: `sq.v −= 4.5f`, отталкивание от точки клика, прищур 0.2 с (`f = S.pokeForce`) |
| 3 клика за 1.6 с | дуется 2.6 с: отворачивается, щёки надуты (`puff`), веко 0.62 |
| 6 кликов за 1.6 с | перегруз 3.2 с (раздел 1.10) |
| двойной клик | радуется 1.1 с, прыжок 5.6, искры (на сцене белые) |
| медленно водить по макушке | гладят: довольные глаза, взгляд вверх, зелёные искры раз в 0.4 с. Условия: курсор внутри тела выше `0.1b`, кнопка не нажата, скорость 15…1400 px/с; накопитель растёт ×1.4/с, падает ×1.1/с, гистерезис 0.55/0.25 |
| перетащить | порог 6 px, тело тянется пружиной, наклон по скорости, глаза широко; отпустить - бросок с инерцией и падение |
| нет движения `S.sleepAfter` (30 с) | засыпает, буквы z раз в 1.7 с; движение будит со вздрагиванием (`wide.v += 7`, прыжок 3.6) |

Состояние «прячется» (`hideUntil`) в прототипе есть, но ничем не включается. Можно оставить как есть или предложить триггер.

- Бесконечные события повторным вызовом выключаются.
- Новое событие сбрасывает выбранный модуль и вкладку на «Главную».

- Ответ на подтверждение (`answer`):
  - «Разрешить» - кнопка становится зелёной «✓ Разрешено», через 0.55 с начинается working, маскот радуется 0.9 с.
  - «Отклонить» - карточка трясётся, через 0.5 с событие снимается, маскот дуется 1.2 с.
  - На вопрос выбранный вариант подсвечивается, через 0.6 с начинается working.
- Шаги агента (`STEPS`, `STEP_LEN = 1.7`) меняются по кругу. В реальном приложении они приходят из хуков PreToolUse и PostToolUse.

### 1.10 Перегруз

- Вход: на 6-м тычке импульс (`sq.v −= 3`, `lean.v += 2.5`). Раскачка `0.08·sin(9t)` и надутость нарастают за 0.9 с.
- Глаза плавно морфятся в спиннеры (пружина `spin`), свечение розовое.
- Остров открывается и держится открытым, пока `alertA > 0.15`. Карточка перегруза и обычное содержимое переходят друг в друга (пружина `alertA`, обычное содержимое уезжает на 6 pt вниз).
- Текст карточки: «Слишком много тыков» и «Перезагружаюсь - вернусь через N с». В конце, пока карточка гаснет, - «Снова на связи». Полоска обратного отсчёта розовая.
- Выход: моргание, прыжок 3.4, голубая вспышка глаз 0.5 с (`rebootAt`), глаза разворачиваются обратно.

### 1.11 Знаки состояний - `stateMarks`, `mascotMarks`, `drawHourglass`

- Размеры знаков зависят от того, где маскот: большой (`R > 16`: сцена, карточка) или нотч.
- Песочные часы:
  - заполненная колба `rgba(255,255,255,0.16)` с обводкой 0.6, рамки сверху и снизу #D5D8DE;
  - янтарный песок #F5A524 сыплется струйкой 3.3 с, горка внизу растёт;
  - за 0.7 с часы переворачиваются, цикл 4 с;
  - стоят справа от маскота на уровне его центра: `mx + 1.42R` (нотч `1.55R`), полувысота `0.34R` (нотч 4.6).
- В нотче при лимите левое ухо чуть шире (52), маскот на `x0 + 21`, чтобы пара «маскот + часы» стояла по центру уха.

### 1.12 Частицы - `particles`, `drawParticles`

- `bit` - квадратики с гравитацией и вращением: искры, конфетти.
- `note` - ♪♫, плывут вверх и покачиваются.
- `z` - буквы сна моноширинным шрифтом.

Частицы рисуются только на большой сцене. При «меньше движения» частиц втрое меньше.

### 1.13 Предметы модулей - `PROPS`, `MODULE_PROPS`, `propFor`, `drawProp`

- **Реестр.** Новый предмет добавляется одной записью `{ look, mood, draw(c, R, b, mc, P) }`. `draw` рисует в пространстве тела: центр тела, ось y вниз, до сплющивания. `look` - куда маскот смотрит с предметом, `mood` - текст слоя.
- **Когда показывается.** Только в карточке выбранного модуля, на «Главной», без событий. У Claude Code - только когда агент свободен: в работе предмет уступает анимации работы.
- **Предметы:**

## 2. Остров

### 2.1 Три состояния - `notchState`

- **Закрыто.** На Mac остров прячется за камерой: остаётся только чёрный вырез. На Windows это плоская плитка 96×9 у верхнего края с полоской статуса 30×3 по центру (серая #4A4D54 или цвет статуса).
- **Полуоткрыто.** Полоса высотой с меню-бар. Слева маленький маскот, справа статус.
- **Открыто.** Большая панель с вкладками.

Режим «Авто» выбирает состояние по правилам, первое подходящее:

1. Курсор над островом → открыто.
2. attention, question, greeting → открыто.
3. Перегруз или `alertA > 0.15` → открыто.
4. Любое событие, перетаскивание, «дуется», «прячется», «гладят» → полуоткрыто.
5. 30 с после запуска → полуоткрыто (`postLaunchUntil`). Срок продлевается, даже если приветствие прервали другим событием.
6. Иначе → закрыто.

### 2.2 Геометрия - `renderIsland`

| величина | значение |
|---|---|
| высота меню-бара `MB` | 32 |
| ширина выреза `NW` | min(190, 0.36·IW) |
| камера | точка r = 3.4 в (cx, 14), #0B0C10, обводка #1B1D25 (только Mac) |
| полуоткрыто, левое ухо | 44 (лимит 52) |
| полуоткрыто, правое ухо | 18 + ширина текста (+26 если эффект «точки»), без текста 50, при подтверждении 44 |
| **центровка** | в полуоткрытом обе половины берут ширину большей, не больше `IW/2 − NW/2 − 10`. Полоса всегда по центру экрана, вместе с камерой |
| полуоткрыто с подтверждением | высота MB + 54 |
| открыто | ширина min(IW − 24, 480), высота 150, уши симметричны |
| скругление низа | 10 + 12·openA, не больше h/2 |
| «плечи» у верхнего края | вогнутый переход f = 6 по бокам (`islandShape`) |

- Переходы: `earL`, `earR`, `ih` (высота), `nw` (база) - пружины группы island. Прозрачности содержимого `halfA`, `openA` - группа fade.
- Windows: та же полоса и те же размеры, что на Mac, только без камеры. В закрытом состоянии база `nw` сжимается до 96, высота до 9. Пилюль и плавающих форм нет - это решение владельца.
- Вспышка обводки на успехе и ошибке (`islandFlash`): `shadowBlur 10`, линия 1.6.
- Тряска при ошибке (`shakeX`): `sin(42t)·3.2·e^(−5t)` 0.7 с. Трясётся только содержимое: вырез - это железо.
- Обводка при запуске (`bootTrace`): короткий светящийся отрезок #7CC4FF один раз обегает контур за 0.75 с.

### 2.3 Полуоткрыто - `drawHalf`

- Маскот R = 11.5 в левом ухе (`x0 + 23`, по вертикали `gy = 27`), со своими знаками событий, точкой статуса и кликабельный.
- Правое ухо, текст начинается от `cx + nw/2 + 9`:
  - Есть статус - текст 12 pt, 500. Перед текстом три волнистые точки, если выбран эффект «точки».
  - Нет статуса - «экипаж»: сетка 2×2 из мини-маскотов модулей R = 5.3 (claude, github, cal, music). Они переглядываются, моргают со сдвигом, показывают своё состояние точкой.
  - Подтверждение или вопрос (`drop`) - под полосой выезжает блок: «Claude Code хочет выполнить» с кнопками «Отклонить» и «Разрешить», или «Claude Code спрашивает» и «наведи на остров, чтобы ответить».
- Эффект «работает» в нотче выбирается: орбита (по умолчанию), точки, блик по полосе.

### 2.4 Открыто - `drawOpen`, `topBar`, `drawOpenBody`

- **Верхняя строка** на уровне меню-бара (y = 16):
  - слева вкладки «Главная», «Чат», «+» (иконки 26×22, активная подсвечена `rgba(255,255,255,0.16)`);
  - справа «Настройки» (шестерёнка) и «Звук» (с перечёркиванием при выключенном).
- **Область содержимого:** от `MB + 2` до `h − 10`, поля 10.
- **Приоритет содержимого:**
  1. приветствие;
  2. перегруз (кроссфейд с остальным);
  3. вкладки «Чат», «+», «Настройки»;
  4. подтверждение или вопрос;
  5. «Главная».
- **«Главная»:**
  - слева карточка выбранного модуля, 52% ширины; справа сетка 2×2 из остальных модулей (иконка-глиф, имя, короткий статус, клик - выбрать);
  - смена модуля: новая карточка въезжает на 8 pt и проявляется за 0.28 с;
  - если выбрана музыка - вместо этого широкий плеер и узкая колонка справа (раздел 2.6).
- **Карточки** - `rgba(255,255,255,0.06)`, скругление 14, тонировка цветом состояния из левого нижнего угла (`cardTint`).
- **Маскот в карточке:** R = 23, центр по высоте карточки, x = X0 + 42, кликабельный, следит за курсором.

### 2.5 Выбор модуля - `autoFocus`, `effectiveFocus`

- Без ручного выбора модуль выбирается по порядку:
  1. success или error → github;
  2. агент занят → claude;
  3. созвон через ≤ 30 мин → cal;
  4. играет музыка → music;
  5. иначе almanac.
- Ручной выбор держится до следующего события.
- Тонировка карточки (`focusTint`):

| когда | цвет | сила |
|---|---|---|
| агент занят | цвет его состояния | 0.3 |
| github: ошибка | красный | 0.45 |
| github: успех | зелёный | 0.45 |
| github: CI идёт | синий | 0.22 |
| созвон через ≤ 5 мин | янтарный | 0.35 |
| играет музыка | мятный | 0.16 |

### 2.6 Карточки модулей - `drawFocusCard`, `drawMusicWide`, `drawRail`

- **Claude Code:**
  - работает - лента из 3 последних шагов: тег инструмента R / E / $ / /, имя файла моноширинным, у правок +N зелёным и −N красным; новая строка въезжает, старые сдвигаются и бледнеют;
  - ищет - «grep … · 14 совпадений»;
  - думает - «планирует изменения»;
  - лимит - «лимит плана исчерпан», «сброс через 1:23», «план Pro · окно 5 часов»;
  - свободен - «последняя сессия 12 мин назад».
- **GitHub:**
  - значок CI (кольцо с галочкой или крестом, при работе крутящаяся дуга) и строка статуса цветом;
  - значок PR и «2 PR ждут ревью»;
  - столбики коммитов за 7 дней (сегодня справа ярче, нулевой день - серая черта) и «34 коммита за 7 дн» с правильным склонением.
- **Календарь:** «через N мин · 15:00», название, следующее событие.
- **Almanac:** три привычки с чекбоксами. Клик переключает: маскот радуется и прыгает, а если отмечены все - праздник.
- **Музыка - полный плеер** (`drawMusicWide`), ширина `X1 − 44`:
  - маскот в наушниках, который танцует;
  - сгенерированная обложка 40×40: градиент, солнце, две волны, которые движутся при игре;
  - название с зелёной точкой (при паузе серой), исполнитель;
  - время, полоса прогресса с перемоткой кликом (при наведении появляется бегунок), оставшееся время;
  - кнопки: перемешать (зелёная, когда включено), назад (если прошло больше 3 с - в начало трека), большая белая «плей/пауза», вперёд, повтор;
  - громкость - иконка и полоса, клик по полосе ставит уровень;
  - трек идёт по времени, в конце включается следующий (с учётом перемешивания и повтора).
- **Колонка модулей** (`drawRail`), ширина 36 справа от плеера: иконки остальных модулей. При наведении плашка плавно выезжает влево с названием модуля (сглаживание ×16/с), клик выбирает модуль.

### 2.7 Подтверждение, вопрос, перегруз, запуск - `drawAsk`, `drawAlert`, `drawLaunch`

- Одна широкая карточка на всю область, тонированная цветом события. Появляется за 0.35 с со сдвигом сверху.
- **Подтверждение:**
  - «Claude Code» и серым «нужно разрешение»;
  - команда печатается по буквам (40 символов/с) с мигающим курсором в тёмной плашке;
  - кнопки «Отклонить [N]» и «Разрешить [Y]» с клавишами в рамках.
- **Вопрос:** текст вопроса и варианты-пилюли с номерами [1] [2] [3]. Варианты появляются по очереди с шагом 0.08 с. Выбранный заливается #22C3E6 с галочкой.
- Снизу полоска оставшегося времени, последние 25% - красным.
- Перегруз - раздел 1.10.
- Запуск - раздел 3.

### 2.8 Настроение маскота по модулю - `moduleMood`

| выбранный модуль | что делает маскот |
|---|---|
| музыка играет | танцует: те же движения, что в празднике, мягче и без конца, прыжок 1.8 раз в 1 с, мятные ноты раз в 0.6 с. «Танец» и «музыка» - одно и то же |
| календарь, созвон через ≤ 5 мин | глаза широко, «торопит на созвон» |
| almanac, все привычки отмечены | довольные глаза, «гордится» |
| остальное | взгляд и подпись из `PROPS`. Если курсор над островом, взгляд следит за курсором |

### 2.9 Вкладки - `drawChat`, `drawAdd`, `drawSettings`

- **Чат:** маскот слева, пузырь «Привет! Чем помочь?», подпись модели «qwen3.5:4b · локально», поле ввода и круглая кнопка отправки. Пока это вид без логики.
- **«+»:** плитки модулей для подключения - Почта, Notion, Obsidian, n8n, Vercel, Grafana.
- **Настройки:**
  - переключатели «Звуки», «Запуск при входе», «Открывать при наведении»;
  - строка «Язык · Русский».

  Повторный клик по шестерёнке возвращает на «Главную».

### 2.10 Клавиши

- 1 Внимание, 2 Работает, 3 Думает, 4 Ищет, 5 Вопрос, 6 Лимит, 7 Успех, 8 Ошибка, 9 Праздник, 0 Привет, Q Сон.
- Во время подтверждения работают Y и N, во время вопроса - 1, 2, 3.
- Клавиши работают и после клика по переключателям. Они игнорируются только в текстовых полях и с Cmd, Ctrl или Alt.
- В приложении эти клавиши - отладочная панель. Боевые клавиши (Y, N, 1-3) работают, когда остров открыт и в фокусе.

## 3. Приветствие при запуске - `trigger('greeting')`, `drawLaunch`

Время от начала события:

| t | что происходит |
|---|---|
| 0 - 0.75 | обводка острова обегается светящимся отрезком |
| 0 - 1.0 | варп: 110 частиц-штрихов вылетают из центра, ускоряясь (`warp^1.8`) |
| 0.6 - 1.4 | в центре разгорается голубое свечение |
| 0.9 | появляется маскот R = 25 в центре, спрятанный в «землю» с закрытыми глазами |
| 1.35 | поднимается, сжатие и разжатие (1.40, 1.80) |
| 1.95 | открывает глаза, голубая вспышка свечения глаз |
| 2.2 - 2.9 | смотрит влево, вправо, потом на курсор |
| 2.9 - 3.95 | довольные глаза |
| 2.95 - 4.05 | машет рукой-кругляшом |
| 2.95 и 3.40 | два прыжка (5 и 3), на 3.02 голубые искры |
| 3.45+ | справа от маскота печатается приветствие по времени суток (26 символов/с, 15/600): «Доброе утро» 5-12, «Добрый день» 12-17, «Добрый вечер» 17-23, «Доброй ночи» |
| 3.8 - 4.6 | частицы мерцают и гаснут, событие заканчивается в 4.6 |

После приветствия остров 30 с держится полуоткрытым. Приветствие не повторяется по клику на маскота.

## 4. Типографика и цвета интерфейса

- Шрифты: Onest 400/500/600 (интерфейс), JetBrains Mono 400/500 (время, команды, файлы), Unbounded 500/600 (заголовки страницы прототипа). В приложении шрифты лежат локально, без запросов к Google: пакеты `@fontsource/*`.
- Текст на чёрном: основной `rgba(255,255,255,0.92)`, приглушённый `T_MUTED = rgba(255,255,255,0.55)`.
- Размеры: заголовок карточки 13/600, строки 11.5/400, статус в нотче 12/500, моно 11.
- Цвета состояний (`STATE_COL`): fail #FF453A, work #3D8BFF, think #A07CFF, ask #F5A524, search #38BDF8, question #22C3E6, limit #8E8E93.
- Обои превью: градиент #2E3442 → #5A6276, меню-бар `rgba(255,255,255,0.09)` (только Mac).

## 5. Инструменты прототипа, которые нужны и в приложении (в dev-режиме)

- **Сцена с большим маскотом:** `R = clamp(0.16·min(W,H), 46, 90)`, земля на 0.74·H, тень, отладочная зона касания.
- **Лупа ×3** по маскоту в пикселях ретины (рисуется с offscreen-канваса 2×, без сглаживания). Главная проверка читаемости в нотче.
- **Панель настроек:** цвет, глаза, пружины, поведение, «меньше движения», зона касания, «скопировать настройки» в JSON, сброс. Значения хранятся в `localStorage` под ключом `notch-mascot-v3`.
- **Три плашки слоёв:** событие, взаимодействие, фон.
- **Кнопки событий** с клавишами.

Всё это остаётся в dev-харнессе (`apps/harness`). В рабочем приложении панель настроек становится вкладкой «Настройки».
