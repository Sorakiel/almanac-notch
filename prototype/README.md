# Прототип

`island-prototype.html` - утверждённая версия 14 артефакта «Маскот острова». Это ровно тот файл, что владелец видел в артефакте, только с добавленными сверху `<!doctype html>`, `charset` и `viewport`, чтобы он открывался сам по себе.

Не редактировать. Если нужно что-то поменять в эталоне - сначала запись в `docs/CHANGES.md` и подтверждение владельца.

Весь код в одном замыкании, функции названы по смыслу (`drawHalf`, `drawOpen`, `eyesOf`, `moduleMood`, `PROPS`...). `docs/SPEC.md` ссылается на них по именам. `tools/snapshot.mjs` при съёмке подмешивает во временную копию отладочный хук `window.__proto`, сам файл при этом не меняется.
